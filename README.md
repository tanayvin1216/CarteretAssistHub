## About

I first built [Food Assist](https://www.carteretfoodandhealthcouncil.org/) for the Carteret County Food & Health Council, a directory that put every food pantry and assistance program in the county in one searchable place. Once it was live, the same gap showed up everywhere else. Housing programs, veterans groups, recovery meetings, foster-care advocates: real help that people could not easily find.

Assist Hub takes the same idea and opens it up to thirteen areas of community need. I'm building it with the Carteret County Democratic Party's Community Service Committee. Residents get one place to search for help. Volunteers get one place to find every open role in the county. And it runs on the same Supabase database as Food Assist, so the two sites stay in sync instead of duplicating each other's work.

## What it does

For residents:

- Browse local organizations across thirteen sectors of need
- Start from "I need help," pick a category, and filter by town or Spanish-language availability
- See one countywide volunteer board and apply to a specific role or send a general application
- Read every public page in English or Spanish

For the committee and partner organizations (admin dashboard + org portal):

- Organizations manage their own listings, hours, and volunteer needs
- Admins manage sectors, organizations, roles, and applications, and feature or reorder listings
- Edit site copy, branding, and the hero image in both languages without touching code

## Built with

- [Next.js 16](https://nextjs.org/) (App Router) and [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/), strict mode
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Supabase](https://supabase.com/) — Postgres, auth, and row-level security, shared with Food Assist
- [Radix UI](https://www.radix-ui.com/) primitives with [shadcn/ui](https://ui.shadcn.com/)
- [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/) for forms and validation
- Hosted on [Vercel](https://vercel.com/)
